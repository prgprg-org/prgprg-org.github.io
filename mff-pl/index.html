Programming Languages at MFF!

This is a support page for the poster about Programming Language courses that we hanged at several place at Math-Phys Faculty; the main purpose is to supply clickable links.

Introductory courses:

  • Principles of Programming Languages (NPRG084, 5 ECTS) by Tomáš Petříček & Vít Šefl
  • Non-procedural programming (NPRG005, 5 ECTS) (typically taught&tutored by many diverse lecturers)

Technical courses:

  • Programming in Haskell (NPRG068, 3 ECTS) by Miroslav Kratochvíl
  • Compiler Principles (NSWI098, 6 ECTS) by David Bednárek & Miroslav Kratochvíl

Advanced and theoretical courses:

  • Theory of Programming Languages (NPRG085, 2 ECTS) by Tomáš Petříček & Vít Šefl
  • Compiler Design (NSWI109, 4 ECTS) by David Bednárek
  • The PRG·PRG reading group is organized at the main PRG·PRG website.
  • The TeX source code of the poster, if you enjoy really convoluted programming languages.
